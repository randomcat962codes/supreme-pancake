# supreme-pancake
A simple program to log the storage cost of any listed directories, giving a simple overview. 
You give the app directories or files you want it to look at on your computer and it will find the storage cost of those applications as well as giving you a total for all the files and directories listed.

## Installation
Currently all users will need to download the source code and compile it themselves with the .NET SDK Ver. 10.
